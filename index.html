Monte Carlo (Every-Visit)

MC updates state values only at the end of an episode using the complete return $G_t$ calculated from that point forward. It does not bootstrap.

G_t = R_{t+1} + γ R_{t+2} + γ² R_{t+3} + ...
V(S_t) ← V(S_t) + α [G_t - V(S_t)]

Temporal Difference (TD(0))

TD(0) updates state values at each transition using the immediate reward and the discounted estimated value of the next state (bootstrapping).

Target = R_{t+1} + γ V(S_{t+1})
V(S_t) ← V(S_t) + α [Target - V(S_t)]
